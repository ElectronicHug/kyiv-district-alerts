## Validation boundaries

The clean-environment check did not log into Telegram or send a real message. Each user must complete login and `--test-send` with their own group. No second production relay was started. Docker, Linux/macOS and the public GCP guide have not yet been executed end to end; Windows local setup is the verified path. GCP commands were checked against official documentation without creating cloud resources. The configured source labels and sample messages do not claim that any real alert happened.

For visual regeneration, run `python -m scripts.render_examples` and capture `docs/demo.html` as `docs/images/telegram-demo.png` with a browser. Re-check the image after changing message formats.
